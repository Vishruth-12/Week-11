# Week 11 — Java Solutions

Solutions for the five sorting assignment problems and ten Category C coding problems.

## Folder structure

### [Sorting](./Sorting/)
- `Problem1_HeightLineUp.java` — Bubble sort; prints each pass.
- `Problem2_PrizeTable.java` — Selection sort in descending order; counts swaps.
- `Problem3_LibraryBookShelf.java` — Insertion sort; prints after each insertion.
- `Problem4_QueueInOrder.java` — Finds the first out-of-order token.
- `Problem5_DiceThrowTally.java` — Counting sort for die values 1 through 6.

### [Category-C-Practice](./Category-C-Practice/)
- `CatalogLookup.java` — Binary search on sorted ISBNs.
- `WarehouseBinGridScan.java` — Grid total and first maximum coordinate.
- `TransactionDuplicateCheck.java` — HashSet duplicate detection.
- `EmployeeIdLookup.java` — HashMap-based employee lookup.
- `PairWithTargetSum.java` — HashSet two-sum for unsorted input.
- `BestSingleTradeProfit.java` — Single-pass maximum stock profit.
- `InsertPositionSortedList.java` — Binary search insertion position.
- `SpiralOrderTraversal.java` — Clockwise spiral traversal.
- `PairSumSortedArray.java` — Two-pointer pair sum.
- `RemoveDuplicatesSortedArray.java` — In-place duplicate removal.
- `PartB_Quiz_Answers.txt` — Part B quiz answers.
- `PartC_Concept_Answers.txt` — Part C concept answers.

## Compile and run

Open the relevant folder, then compile an individual Java file using its filename:

```bash
javac Problem1_HeightLineUp.java
java HeightLineUp
```

Use the matching source filename and public class name for the other programs. The solutions avoid `Arrays.sort()`.
